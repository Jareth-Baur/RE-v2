# Generals Zero Hour Reborn v5.0 (Modified)

A community-maintained source repository containing editable assets for a customized version of **Command & Conquer: Generals – Zero Hour Reborn v5.0**.

> **Note:** This repository only contains the editable source files used for modding. Compiled game assets (`.big` files), executables, and other game files are intentionally excluded.

---

## Features

- Custom gameplay balance changes
- INI modifications
- UI/Menu adjustments
- Art asset modifications
- Bug fixes and gameplay improvements
- Easy to track changes with Git

## Installation

### For Players

1. Download the latest release.
2. Extract the archive into your **Command & Conquer: Generals – Zero Hour** installation directory.
3. Launch the game using the provided launcher or shortcut.

### For Developers

Clone the repository:

```bash
git clone https://github.com/Jareth-Baur/RE-v2.git
```

Only the editable source files are included in this repository:

- `Art/`
- `Data/`
- `Window/`

After making changes, rebuild the mod archive (e.g., `!RebornV5-REv2.big`) using your preferred BIG archive tool, then replace the existing archive in your Zero Hour Reborn installation.
